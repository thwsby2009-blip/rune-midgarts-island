# 仙境傳說島

## 普隆德拉 3D 城內版

按右上「進入普隆德拉 3D」或城市介紹卡的「進入城內 3D」，可以進入以提供的配置圖為參考製作的風格化立體城鎮。模型包含南門、城牆、王宮、雙塔大教堂、中央噴水池、石板大道、商店與住宅、市集攤位、花園、街燈和長椅；建築外觀與尺寸為設計配置，並非官方遊戲模型或精確復刻。

城內支援人物選擇、換職業、鍵盤與螢幕方向鈕行走。點選街道會以導航網格自動繞過建築與噴水池；點到建築會選取鄰近可行走地面。城內導覽可拉近各個地標，再按「步行前往」。右上按「返回世界地圖」回到進城前的位置。`#city=prontera&view=interior` 可直接開啟城內。

原始配置圖片仍可由城內側欄「查看原始配置圖」開啟。房屋與地標外部可探索，尚未製作建築內部房間、NPC 對話、戰鬥或多人連線。城外世界地圖仍是平面底圖配立體人物；其餘城市未建立城內場景。

`dist/prontera.js` 定義建築、街景、碰撞區與地標；`dist/navigation.js` 負責碰撞及尋路。靜態建築依材質合併以減少繪製次數，城內陰影只於進城時更新。`npm run check` 包含導航的繞路、建築點擊、邊界與不可達目的地檢查。

## Q 版職業探索版

初次進入可以選擇劍士、魔法師、服事、盜賊、弓箭手與商人。六個職業均為原創程式模型，依使用者提供的人物圖參考髮色、服裝與職業裝備，選角縮圖與實際操控人物使用同一模型。

點選地圖步行到目的地；WASD、方向鍵或按住螢幕方向鈕自由移動。鏡頭可跟隨人物，亦可拖曳自行瀏覽、按「跟隨人物」回到角色。可隨時更換職業，角色位置不變。瀏覽器記住上次的職業，重新開啟從普隆德拉出發。不儲存行走位置。

世界地圖目前是自由探索模式，移動限制在地圖外框，尚未設計陸海碰撞。普隆德拉城內已加入建築碰撞與尋路。六種職業的差異為外觀與裝備，同一場景內移動速度相同；尚未加入職業戰鬥能力或多人同步。魔物維持待補。

解壓縮完整專案後，在已安裝 Node.js 的 Windows 電腦雙擊「啟動預覽.cmd」，於瀏覽器開啟 http://127.0.0.1:8033 。按 Ctrl+C 停止。

## 城市地圖

普隆德拉介紹卡保留「城內地圖」，展示使用者提供的城內街道與設施註解圖，附巴哈姆特介紹連結，並可進入 3D 場景。巴哈頁面在收錄時回傳 403，未擷取該頁內容。

互動城市地圖第一版。使用使用者提供的世界地圖，包含 26 筆城市／周邊區域索引，14 處概念位置光標、中英文搜尋、地區篩選、介紹卡、鏡頭定位、2D／3D 視角、可分享的城市網址，以及無 WebGL 時的平面顯示。

這是平面底圖搭配立體定位光標的原型，尚非完整立體島嶼地形。城市位置是配合概念圖的設計配置，非官方遊戲座標。未能確認的外域位置留在索引，不虛構座標。使用者清單中的重複與待核對名稱已在介面標記；描述取自使用者提供內容。

魔物尚未加入。使用者提供的舊版地圖在 `references/`，未部署到網站。後續先核對圖上數字是等級或其他標記，再建立魔物資料。

執行 `npm run check` 檢查語法，`npm run preview` 開啟本機預覽。網站靜態檔案位於 `dist/`，無須安裝套件。Three.js 與 OrbitControls 沿用既有專案中的 MIT 授權版本，授權全文見 `dist/vendor/LICENSE-three.txt`。世界地圖圖片由使用者提供。
